# Как добавлять свой контент

Всё встроенное содержимое лежит в `data/*.json`. Двигаться удобнее через исходники в `tools/` — они превращаются в JSON одной командой:

```bash
python3 tools/build_data.py     # пересобирает data/words.json, questions.json, lessons.json, prompts.json, sources.json
```

> ⚠️ Авторское право: не вставляй в проект тексты и словари защищённых книг (Cambridge IELTS, Barron's, Official Digital SAT Study Guide и т. п.). Слова и тексты из своих копий книг добавляй **только у себя в браузере** (раздел «Книги» и «Читалка») — они хранятся на твоём устройстве и не попадают в репозиторий.

## 1. Свои слова из книги (без правки кода)
Раздел **Практика → Книги и домашки**:
1. Выбери книгу из списка (список задаётся в `config.js → books`).
2. Вставь слова или загрузи `.txt`:
   ```
   #12                          ← номер страницы
   abandon - покидать - to leave completely
   acquire - приобретать
   #13
   adequate - достаточный | enough for a purpose
   ```
   Разделитель между полями: ` - `, `;`, `|` или Tab. Третье поле (определение) необязательно.
3. Поставь домашку: «выучи слова со стр. 12–13». Кнопка **Экзамен** берёт случайные слова из этих страниц; тип вопросов зависит от твоего уровня: низкий — слово→перевод, средний — определение→слово, высокий — определение + написание + предложение.

## 2. Свои тексты в читалку
**Практика → Читалка → Добавить свой текст**: вставка, `.txt`, `.md`, `.html` или `.epub`. PDF без внешней библиотеки в браузере не разобрать — скопируй текст.

## 3. Добавить слова в основной словарь
Отредактируй `tools/words.txt`, одна строка = одно слово:
```
слово|часть речи|перевод|определение по-английски|пример|тема|уровень(1-3)
```
затем `python3 tools/build_data.py`.

## 4. Добавить вопросы
В `tools/build_data.py` используй помощники `G(...)` (grammar), `RQ(...)` (reading), `LQ(...)` (listening), `SQ(...)` (SAT R&W), `M(...)` (SAT Math):

```python
G('g26','grammar','articles',2,'___ sun rises in the east.',['A','An','The','–'],2,
  'Уникальный объект → the.',                       # объяснение (HTML допустим)
  ['A — для одного из многих.','An — не по звуку.','','Артикль нужен.'])   # почему неверен каждый вариант ('' у правильного)
```
Поля: `id` (уникален), `skill` (`grammar|reading|listening|rw|math|vocab`), `topic` (связывает с уроком и журналом ошибок), `lvl` (1–3), текст, варианты, индекс правильного, объяснение, причины.
Для Reading/Listening сначала добавь текст в `passages` / `listening`, затем вопрос с `passage='p3'`. Чтобы в разборе подсвечивалось место ответа — добавь фразу в словарь `KEYS`.
Обязательно указывай источник (`src=`) и лицензию — они показываются в «Откуда материалы».

## 5. Добавить урок
В списке `lessons` (`tools/build_data.py`):
```python
L('gr5','grammar','both','Модальные глаголы','🔧',10,'modal',
  ['Пункт объяснения 1','Пункт 2'],   # появляются по очереди с анимацией
  'Пример: You <b>mustn’t</b> smoke here.',
  task=None, tip='Совет от Миши')
```
`topic` определяет, какие вопросы войдут в практику и мини-тест. Для Writing/Speaking укажи `task={'type':'writing','id':'t2'}` или `{'type':'speaking'}`. Новый модуль добавь в `modules`.

## 6. Задания Writing / Speaking
Файл `data/prompts.json` формируется в `build_data.py` (блок `prompts.json`): `writing` — список заданий (`min`, `minWords`, `exam`), `speaking` — вопросы Part 1/3 и карточки Part 2.

## 7. Источники
Каждый материал должен быть описан в блоке `sources.json` (`cat`: `own | open | ai | user`, `license`, `year`) — экран «Откуда материалы» строится из него.

## 8. ИИ-генерация (нужен ключ)
Если подключён Groq/Gemini, сайт сам создаёт: определения слов, мнемоники, упрощённые тексты, вопросы к любому тексту, похожие задания «Теперь попробуй сам», проверку Writing/Speaking. Все ответы кэшируются в IndexedDB и помечаются «ИИ».
