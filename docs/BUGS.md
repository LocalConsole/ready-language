# Баги старой версии (vanilla JS) — найдены при аудите

Аудит: сайт запущен в headless Chrome, пройдены онбординг, все маршруты, уроки, словарь, читалка, экзамены, три языка, мобильная ширина.

| # | Баг | Где | Исправление в React-версии |
|---|-----|-----|-----------------------------|
| 1 | Skip-link `href="#view"` ломает hash-роутер: переход на главную, текущая страница теряется | index.html | Ссылка переносит фокус на `<main>`, маршрут не меняется |
| 2 | «Разбор ошибок» хранился только в памяти: после перезагрузки «Ошибок нет — редкая чистота!» | ui.js `App.review` | Последний разбор хранится в IndexedDB |
| 3 | Экспорт прогресса включал API-ключи пользователя | core.js `Store.export` | Экспорт содержит только учебные данные; ключ лежит в localStorage настроек |
| 4 | Импорт без валидации; HTML из `expl` вставлялся как есть (stored XSS через файл импорта) | core.js `Store.import`, ui.js | `normalize()` проверяет структуру; весь HTML проходит санитайзер с белым списком тегов без атрибутов |
| 5 | Английский интерфейс переведён на ~60 строк, остальное по-русски | i18n.js | Полные словари en/uz, тест на отсутствие кириллицы в UI |
| 6 | Узбекский — глобальный MutationObserver по всему DOM и подмена `alert/confirm`, перезагрузка страницы при смене языка | uz.js | Переводы через `t()`, смена языка без перезагрузки |
| 7 | Тёмная тема: счётчик слов светлый фон + светлый текст; пилюли `.pill.*` нечитаемы | style.css, views2.js | Токены темы, тёмные варианты |
| 8 | Горизонтальный скролл на 375px в «Книги» и «Читалка» | style.css | `overflow-wrap`, `max-width` |
| 9 | Service worker cache-first, версия кэша вручную (`misha-v6`) — пользователи видят старый сайт | sw.js | vite-plugin-pwa, precache с хешами, autoUpdate |
| 10 | `long:true` ставился на любые длинные запросы (упрощение текста, генерация вопросов) | ai.js | `long` только для Writing/Speaking и разбора ошибок |
| 11 | Ключи/провайдеры Groq/Gemini/OpenRouter в браузере как основной путь, паузы по провайдерам | ai.js | Один модуль `lib/ai.ts` → прокси; свой ключ — запасной вариант; cooldown после ошибки |
| 12 | Забытая SRS-карточка (`q<3`) возвращалась «сегодня же», хотя интерфейс обещает «повтор завтра» | core.js `SRS.grade` | Возврат на следующий день |
| 13 | Слово из книги со спецсимволами (`(to) go`, `e.g.`) ломало `RegExp` в вопросе-пропуске → падение теста | ui.js `makeVQ` | Экранирование регулярки |
| 14 | Вопрос «найди ошибку в написании» для коротких слов имел 1 вариант | ui.js `mutate` | Откат к другому типу вопроса |
| 15 | Утечка: при уходе со страницы середине теста Promise/таймеры оставались висеть | ui.js `Quiz.run` | Компонент с жизненным циклом React |
| 16 | Калькулятор SAT на `Function()`/regexp-белом списке | views2.js | Собственный безопасный парсер выражений |
| 17 | Прогресс в localStorage (лимит ~5 МБ, синхронные записи), `confirm()` при сбросе | core.js | IndexedDB (Dexie), встроенное подтверждение; миграция старого `misha.state` |
| 18 | При смене даты назад «серия» обнулялась | core.js `touchDay` | Защита от отрицательного промежутка |
| 19 | Дата экзамена могла быть в прошлом | views1.js | Валидация |
